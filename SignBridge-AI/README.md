# ASL Sign Language Recognition

Real-time American Sign Language (ASL) recognition for letters A–Z and digits 0–9 using a CNN trained on static hand-sign images. A FastAPI backend serves both the prediction API and the single-page frontend.

---

## Project Structure

```
d:\sign\
├── main.py              # FastAPI server (prediction endpoint + static serving)
├── train.py             # CNN training script
├── requirements.txt     # Python dependencies
├── README.md
├── classes.txt          # Generated by train.py — ordered class labels
├── sign_image_model.h5  # Generated by train.py — trained Keras model
├── static\
│   └── index.html       # Single-page frontend (Tailwind CSS + vanilla JS)
├── tests\
│   ├── __init__.py
│   ├── conftest.py      # Pytest fixtures (builds dummy model for tests)
│   └── test_api.py      # Integration tests
└── Image_Data\          # Place your dataset images here (see below)
```

---

## Requirements

- Python 3.10 – 3.13
- A CUDA-capable GPU is optional (CPU training is slower but works)

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Dataset Layout

Organise your images under `Image_Data/` with one sub-folder per class:

```
Image_Data\
├── A\
│   ├── img001.jpg
│   └── img002.jpg
├── B\
│   └── ...
...
└── 9\
    └── ...
```

Supported image formats: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff`.

---

## Training

```bash
python train.py
```

This will:
1. Load and preprocess all images from `Image_Data/`.
2. Train the CNN for 20 epochs.
3. Print final training and validation accuracy.
4. Save `sign_image_model.h5` and `classes.txt` to the project root.

Training with a typical ASL dataset (thousands of images per class) takes a few minutes on GPU.

---

## Running the Server

The server requires `sign_image_model.h5` and `classes.txt` to exist (generated by training).

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Then open your browser at **http://localhost:8000**.

---

## Using the Frontend

1. Allow webcam access when prompted.
2. Position your hand inside the **green bounding box**.
3. The predicted character and confidence score update every 400 ms.
4. Characters with confidence above the **threshold slider** (default 0.80) are appended to the sentence builder.
5. Use **Backspace** to remove the last character or **Clear** to reset.

## API Reference

### `POST /predict`

Accepts a base64-encoded JPEG/PNG image and returns the top-1 prediction.

**Request body:**

```json
{
  "image": "<base64-encoded image string>"
}
```

**Response (200 OK):**

```json
{
  "character": "A",
  "confidence": 0.9873
}
```

**Error responses:**

| Status | Reason |
|--------|--------|
| 400    | Invalid or un-decodable base64 payload |
| 500    | Internal inference error |

### `GET /`

Returns the frontend HTML page (`static/index.html`).

## CNN Architecture

| Layer | Details |
|-------|---------|
| Input | 64 × 64 × 3 |
| Conv2D + MaxPool | 32 filters, 3×3, relu, same padding |
| Conv2D + MaxPool | 64 filters, 3×3, relu, same padding |
| Conv2D + MaxPool | 128 filters, 3×3, relu, same padding |
| Flatten | — |
| Dense | 256 units, relu |
| Dropout | 0.5 |
| Dense (output) | 36 units, softmax |

Compiled with the **Adam** optimiser and **sparse categorical cross-entropy** loss.

## Customisation

| Setting | Where | Default |
|---------|-------|---------|
| Confidence threshold | Frontend slider | 0.80 |
| Capture interval | `CAPTURE_MS` in `index.html` | 400 ms |
| Bounding box position/size | `BBOX` in `index.html` | x=160, y=60, w=200, h=200 |
| Training epochs | `epochs` in `train.py` | 20 |
| Input image size | `IMG_SIZE` in `train.py` / `main.py` | 64 px |

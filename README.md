# SignBridge AI
## Overview

SignBridge AI is an AI-powered accessibility solution designed to bridge the communication gap between the deaf and hearing communities. The project uses Artificial Intelligence, Computer Vision, and Embedded Systems to translate Indian Sign Language (ISL) gestures into real-time text and speech.

The system captures hand gestures using a camera, detects hand movements using MediaPipe, and recognizes signs using a TensorFlow-based machine learning model. The recognized gestures are converted into text and audio output, enabling faster and more effective communication.

SignBridge AI also supports two-way communication by converting spoken language into text, helping sign language users communicate independently in daily situations.

---

## Features

- Real-time Indian Sign Language (ISL) recognition
- AI-based gesture detection and classification
- Hand landmark tracking using MediaPipe
- TensorFlow-based sign recognition model
- Text-to-Speech conversion
- Speech-to-Text support for reverse communication
- Emergency gesture detection system
- Portable smart glasses/device integration
- IoT-based alert mechanism

---

## Working Principle

1. The camera captures the user's hand gestures.
2. MediaPipe identifies hand landmarks and movement patterns.
3. The extracted data is processed by the trained TensorFlow AI model.
4. The model predicts the corresponding sign.
5. The output is converted into text and speech.
6. Emergency signs trigger alerts through connected hardware.

---

## Emergency Assistance Feature

SignBridge AI can identify important emergency gestures such as:

- Help
- Call Doctor
- Fire
- Chest Pain

When an emergency gesture is detected, the system can activate alerts using a buzzer, display notifications, and connected IoT devices.
